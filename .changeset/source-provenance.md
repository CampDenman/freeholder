There is a /source page now that answers "what is this instance actually
running?" — the version, every installed plugin with its licence and what it is
allowed to do, third-party notices, and every change the builder actually made,
with a link to the pull request where a code change came from.

It only lists changes that were applied. A proposal you never accepted did not
change anything, so it does not appear.

It is for you, not the public: you have to be signed in. Running modified
software over a network does not oblige anyone to publish those modifications,
and a list of your plugins and changes is the first thing someone attacking
your site would want.
