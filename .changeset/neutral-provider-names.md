Provider choices now carry neutral names, and no provider is picked for you. The site builder and managed agents can use any OpenAI-compatible gateway (`gateway`: set `AGENT_GATEWAY_URL`, `AGENT_GATEWAY_API_KEY` and `AGENT_GATEWAY_MODEL`), with Paradise Modern's hosted gateway listed as one optional provider (`paradise`). A gateway connection that points at a different address from `AGENT_GATEWAY_URL` must name its own key, so your instance-wide key is never sent anywhere else. The voice and video settings no longer preselect or label any provider as "first-party": choose Daily or Paradise Comms when you set calls up. Nothing breaks for existing sites: `FREEHOLDER_AGENT=pm_brain`, `PARADISEMODERN_API_KEY`, `PARADISEMODERN_URL`, saved voice/video settings and managed connections saved as `pm_brain` keep working exactly as before. The old `pm_brain` name is deprecated but still accepted. If you roll back to an earlier version after switching, set `FREEHOLDER_AGENT` back to `pm_brain` (earlier versions do not understand `paradise` or `gateway`), and re-create any managed connection you added as `paradise` or `gateway` under the old name.
