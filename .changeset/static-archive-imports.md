Import a static website ZIP into editable CMS drafts with local media, original SEO metadata and file-address redirects. The owner can review files and media left out before publishing, and retry the same source without duplicating accepted assets. A matching reupload can resume an expired private source; changed exports require a new run.

WordPress and archive imports now accept an asset and its source receipt in one transaction, preserving recovery after lost responses and refusing late workers whose source claim was replaced. Source reads and ZIP expansion remain bounded; this increment does not remove the larger-source batch limits in C3.22.
