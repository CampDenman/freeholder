Received returns can send refunds through their original payment providers and accounts. Every installment is reserved before provider I/O; a return closes only when its full refund is confirmed. Connection failures reuse the frozen request, and a new attempt after a definite refusal refunds only the remaining balance. Return credits preserve the original discounts and tax, including rounding across separate returns. The owner action is translated into all four locales and requires fresh human verification (C5.19/C11.10).
