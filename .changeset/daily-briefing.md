There is a daily briefing now, at /admin/briefing: one screen answering what
needs you, what is on today, and what changed while you were away — in that
order, because the things that need you should not be below the things that do
not.

It is built each morning before you arrive rather than when you open it, so the
page loads as fast as any other and the work behind a section has already
happened.

Sections come from whatever your site is actually running, not from a fixed
list, so a briefing gains a section when you switch a module on. If one section
cannot be produced, you still get the rest — this is the screen that tells you
when something is wrong, so it has to survive something being wrong.

A quiet day says so instead of padding the page, and empty sections are left
out entirely.

You can hide any section you do not want to read. Hiding only hides: the work
behind it carries on, and you can bring it back whenever you like.

This release is the briefing itself. What core puts in it — today's
appointments, new enquiries, overdue invoices, anything that needs
reconnecting — follows next.
