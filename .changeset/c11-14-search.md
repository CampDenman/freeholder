Search across the records you already own. Type one query in admin Search and
it looks through contacts, conversations, notes, tasks, invoices, pages, media,
products, quotes, projects and galleries you have access to — the same
Postgres rows, not a second index to keep in sync.

Staff only see kinds their role can already open. This is not undelete for
every row, and it does not add a retention clock to every table (C11.14).
