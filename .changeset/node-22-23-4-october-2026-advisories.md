The Freeholder image now runs on Node.js 22.23.4, the 21 October 2026 security release. It fixes a Brotli decompression flaw that could corrupt memory, two ways a server could pass certificate checks for an IP address it was not issued for, a DNS lookup that could silently answer for a different name, and a reused connection accepting a reply sent before the request. It also stops trusting the eight eMudhra intermediate certificates whose keys were compromised. This matters because your site talks over encrypted connections to your payment, mail and storage providers. Self-hosted sites get the fix by pulling the new image and restarting. The sample proxy settings for droplets and the host updater now also refuse Next.js's unused image-resizing address. The site itself already refused it. The new release also carries the 2026 time zone rules for British Columbia (permanent UTC−7 from 1 November), Alberta, the Northwest Territories and Manitoba, so bookings, reminders and reports there keep the right time after the date the clocks would have gone back. Booking pages now name a time zone the way people say it all year, such as "Pacific Time (Vancouver)", instead of a "Daylight" or "Standard" name that can be wrong in winter.
