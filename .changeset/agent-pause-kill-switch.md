Pause now means stop. Pausing one worker — or hitting the kill switch for all of them — ends the runs they are holding instead of leaving them to finish the rest of a ten-minute lease: each run is cancelled, its lease cleared, and its task handed back to the queue so nothing is lost. A managed run in flight notices within one turn. Both controls live on the work board as ordinary buttons that work without JavaScript, because the moment you need them is the worst moment to discover a page did not load.
