The dashboard's "What changed" no longer fills up with the work Freeholder does while installing a site's starting content: those changes are still kept in the full log, labelled "Site setup", but stay out of the default view. When the same thing happens several times in a row, such as a bulk edit, the feed now shows it once with a count ("Freeholder updated pages ×15") so the other recent news stays visible. In the public demo, the feed now opens on the sample business's recent enquiries, orders, bookings, messages and payments, each marked "(sample)". Sample business history can only be added by a demo deploy, never by a person or an API key on a real site.
