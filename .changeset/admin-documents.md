Documents have their own admin screens. Create one, add a revision, share it with a link, a password or a signed-in customer, set an expiry and a download limit, and see exactly who opened it — including who was turned away and why.

A share link is shown once, when it is created, with a plain warning that it cannot be shown again: only its fingerprint is stored, which is what stops a copy of the database being a set of working links.
