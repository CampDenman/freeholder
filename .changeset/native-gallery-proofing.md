Add the native galleries tab and proofing screen (C10.27). Customers open a gallery with the existing login mutation, then read the live session and mark, clear or submit choices through the same services as the website. Private image bytes from `/g/{slug}/view/{itemId}` share the 60-second encrypted cache lease: denials evict immediately, offline failures never renew access, expiry clears displayed photos, and a late request from a signed-out session cannot refill the next account. Proofing writes are live-only. The invoices tab is now included in the customer tab order.
