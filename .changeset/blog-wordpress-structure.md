Organize blog posts with categories, tags and guest or account-linked authors, and manage moderated reader comments from the owner dashboard. WordPress imports now create those records, preserve original post addresses, full search titles, descriptions, post dates and supported search/social metadata, and carry approved and held reader comments into the moderation queue. Reader email stays private and participates in contact merge, export and erasure.

Old query-ID and attachment links receive permanent redirects when an import is published; date archives and legacy pagination remain usable. Redirects resolve directly to the final destination before a trailing slash is removed. The import report records source features that still need review before DNS cutover, including the reserved member-feed path and metadata absent from a WordPress export.
