An agent can now be given one connected account rather than all of them. Scopes say what kind of work a worker may do; they never said whose mailbox or whose calendar, so reaching a connected account is now a separate grant you make one agent and one account at a time — and an agent sees only what it was given, never a credential, and never that the other accounts exist. Taking access back does not need a second factor, because removing it should never wait. If a provider withdraws consent, every grant on that account goes with it in the same breath; if a token simply expires, the grants survive and the reconnect notice tells you how many agents are waiting on it.
