Answer the same question once. The help centre is a knowledge base built from
the pages you already know how to write — same editor, same languages, same SEO
— so an article is a page you filed under a category rather than something you
learn a second tool to publish.

Readers search by typing a fragment of the problem, and the search looks inside
the article, not only at its title. Each article asks whether it helped, with
two buttons and no comment box, and the admin lists the articles people said did
not help first — which is the one worth an afternoon.

Deleting a category never deletes the writing in it: those articles stay
published at the same address, simply uncategorised.
