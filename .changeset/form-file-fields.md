Forms can now ask for a file. A file question accepts audio, documents or images up to a size the owner chooses, within the site's media limits. A signed-in customer uploads it privately through the same resumable uploader as the media library, and the form carries only the uploaded file; a visitor who is not signed in is asked to sign in first. Wrong file types and files that are too large are refused with a clear message, a file cannot be attached twice, and only the owner and staff can open it, from the form's submissions. The file is included in the customer's data export and removed when their data is erased.
