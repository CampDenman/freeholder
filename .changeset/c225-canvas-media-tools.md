Pictures can now be uploaded, cropped and focused where they render. The image picker on the editor canvas has an "Upload image" button: the file goes through the same resumable upload the media library uses — a dropped connection picks up where it stopped — and the new picture lands on the block the moment it is ready, with no trip to the library. A "Crop & focus" button on any image opens a crop tool beside it: click the picture to mark its subject, choose a frame shape (original, wide, landscape, square or portrait) and, if you want, drag a crop window with corner handles. Every control also works from the keyboard. A small preview shows exactly what the page will show, Apply saves at once and can be undone in one step, and your original file is never altered — the same photograph can be a wide banner on one page and a square on another. The focal point you set in the media library is now honoured whenever an image is framed tighter than its own shape.
