## Exceptions that must stay explicit

The manual binding branch intentionally does not demand a Stripe route or
provider cash observation. Its independent final `guard_commercial_attestation`
requires the actual original manual subscription payment, seller-merchant
policy at collectionVersion0, issued invoice, exactly one matching frozen tax
party/profile/version, actual amount/currency, allowed manual method, created
state and no preexisting provider reference/route. It retains pending siblings,
contradictory positive observations and unfinished creator refusal. Its fee
branch uses the accepted gross duty rather than inventing a collected fee.
This branch is not a global exemption for arbitrary manual rows.

The proration agreement-route branch intentionally conserves the duty's
remaining CASH principal and cash fee target, including carried original
credit and separately retained fee receivable. It requires the exact duty,
current actual cash projection, one retained original cash/fee origin and no
refunded prior cash. It cannot be replaced by the old full-gross invoice ratio;
the historical ordinary provider branch remains unchanged below it.

The new terms branch is an intentional gross-receipt alternative to full-period
amendment timing. It binds the actual accepted proration, prior revision,
snapshot/profile/tax destination/notice, original parent calendar and future
effective instant, and refuses a later revision or billed target boundary.
The companion immutable proration receipt checks current parent/pending-plan,
latest actual previous terms, original paid-line/calendar ancestry and no
unresolved other change. A previous acceptance at the same original period-end
boundary is allowed only through an already applied actual proration. Blindly
reintroducing the ordinary `effective_period_start > prior.effective_period_start`
condition into this new branch would reject legitimate successive mid-cycle
changes sharing the retained original calendar. Ordinary amendment and late
resumption retain their exact stricter original predicates.

## Assembly and qualification dependency

SQL80 has THREE historical definitions of commercial terms: initial2581,
amendment3795 and late-resumption4081. Use the FINAL4081 authority for any
reconciliation. The frozen gross replacement already contains that final
resumption behavior. The other four base functions have one qualified0cff
definition each; no hidden later redefinition was found by source search.

the attestation suffix, then replaced by gross and finally agreement-fee

boundary → card; the final fee definition must win. That final definition
retains the original attestation origin/caller/refund/remittance checks while
adding exact carried-duty cash fee allocation. Do not treat the extractor's
extra tail-only duplicate as a missing older-base guard or copy the first
definition over this final one.
